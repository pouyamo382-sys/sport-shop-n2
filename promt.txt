برای استفاده از فونت **Vazirmatn** در کد CSS شما، ابتدا باید لینک فونت را به `<head>` فایل HTML خود اضافه کنید. سپس، برای استفاده از این فونت در CSS، می‌توانید از کلاس‌ها یا فونت‌فمیلی که تعریف کرده‌اید استفاده کنید.

### گام اول: لینک فونت به HTML

در بخش `<head>` فایل HTML خود، لینک زیر را اضافه کنید:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Vazirmatn:wght@100..900&display=swap" rel="stylesheet">
```

### گام دوم: استفاده از فونت در CSS

برای استفاده از فونت **Vazirmatn** در CSS شما، باید به جای فونت **Poppins** که در حال حاضر استفاده می‌کنید، از فونت **Vazirmatn** استفاده کنید. به این صورت:

```css
body {
  font-family: 'Vazirmatn', sans-serif;
  background-color: var(--background);
  color: var(--text);
  line-height: 1.6;
  text-align: right; /* راست‌چین کردن تمام متن‌ها */
}
```

اگر می‌خواهید از ویژگی‌های مختلف فونت **Vazirmatn** مثل وزن‌های مختلف آن استفاده کنید، می‌توانید کلاس‌های خاصی ایجاد کنید:

```css
.vazirmatn-light {
  font-family: 'Vazirmatn', sans-serif;
  font-weight: 100; /* برای سبک‌ترین وزن */
}

.vazirmatn-bold {
  font-family: 'Vazirmatn', sans-serif;
  font-weight: 700; /* برای وزن بولد */
}
```

این کد CSS را به کد قبلی خود اضافه کنید تا از فونت **Vazirmatn** به‌طور کامل استفاده کنید.
  توضیح بده این چیزایی که برای فونت نوشتی را چط.ری در کد هام استفاده کنم   

خیلی خوب، قدم به قدم توضیح می‌دم که این بخش‌های مربوط به فونت **Vazirmatn** چطور در کد شما استفاده می‌شوند.

## 1️⃣ اضافه کردن فونت به HTML

اول باید فونت را از گوگل فونت بارگذاری کنید. این کار باعث می‌شود مرورگر فونت را بشناسد:

```html
<head>
  <!-- بارگذاری فونت Vazirmatn از گوگل -->
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Vazirmatn:wght@100..900&display=swap" rel="stylesheet">
</head>
```

> این لینک‌ها فقط یک بار در `<head>` نیاز است.

---

## 2️⃣ استفاده از فونت در کل سایت

اگر می‌خواهید کل متن سایت شما از این فونت استفاده کند، کافی است در `body` فونت را تعریف کنید:

```css
body {
  font-family: 'Vazirmatn', sans-serif;
}
```

> الان دیگر نیازی به `font-family: 'Poppins', sans-serif;` ندارید، می‌توانید آن را با Vazirmatn جایگزین کنید.

---

## 3️⃣ استفاده از وزن‌های مختلف فونت

فونت **Vazirmatn** وزن‌های مختلفی دارد (100 تا 900). اگر بخواهید مثلا یک تیتر بولد و یک متن سبک داشته باشید، می‌توانید کلاس‌های CSS بسازید:

```css
.vazirmatn-light {
  font-family: 'Vazirmatn', sans-serif;
  font-weight: 300; /* سبک */
}

.vazirmatn-regular {
  font-family: 'Vazirmatn', sans-serif;
  font-weight: 400; /* معمولی */
}

.vazirmatn-bold {
  font-family: 'Vazirmatn', sans-serif;
  font-weight: 700; /* بولد */
}
```

و بعد در HTML یا CSS از این کلاس‌ها استفاده کنید:

```html
<h1 class="vazirmatn-bold">تیتر سایت</h1>
<p class="vazirmatn-light">متن توضیحی سبک</p>
```

یا داخل CSS برای یک بخش خاص:

```css
.hero h1 {
  font-family: 'Vazirmatn', sans-serif;
  font-weight: 700; /* بولد */
}
```

## 4️⃣ نکته درباره "font-optical-sizing" و variable font

فونت Vazirmatn یک **variable font** است؛ یعنی وزن‌ها و ضخامت‌ها را می‌توان به راحتی تغییر داد. اگر بخواهید تنظیمات پیشرفته‌تری داشته باشید:

```css
.custom-text {
  font-family: 'Vazirmatn', sans-serif;
  font-weight: 500; /* هر عدد بین 100 تا 900 */
  font-optical-sizing: auto; /* تنظیم بهینه اندازه و فاصله حروف */
}
```

> این باعث می‌شود ظاهر متن در اندازه‌های مختلف بهتر و خواناتر باشد.

---

💡 خلاصه‌ی سریع:

1. لینک گوگل فونت را به `<head>` اضافه کنید.
2. `font-family: 'Vazirmatn', sans-serif;` را به `body` یا هر المنتی که می‌خواهید بدهید.
3. برای وزن‌های مختلف، کلاس‌های CSS بسازید و روی تگ‌ها اعمال کنید.
